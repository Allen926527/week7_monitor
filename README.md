# Linux Monitor

一个基于 Python + Linux Shell 的系统监控工具。

## 项目简介

Linux Monitor 可以获取 Linux 系统的 CPU、内存、磁盘和系统负载信息，并进行健康状态分析。

项目同时支持：

- 系统健康检查
- 监控报告
- 日志记录
- 后台运行
- PID 进程管理
- Shell 启动
- Cron 自动执行
- Git 版本管理
